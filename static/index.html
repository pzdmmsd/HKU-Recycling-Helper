    A LITTLE CONTEXT

    Clarity, with the sources
    to back it up.

    Describe one everyday item in any language, including its material and whether it is empty, clean, or contaminated. Typos are accepted and normalized before the evidence check. The pilot only covers the re Kiosk on Main Campus.

    1. 01

      Check the scope

      Hazardous, laboratory, and commercial waste requests are refused. Campus staff and signage always take priority.

    2. 02

      Look for cited evidence

      Live mode retrieves relevant records from the local collection included by the project team. It does not search the web or find the nearest bin.

    3. 03

      Make the uncertainty visible

      You’ll see Accepted, Not accepted, Cannot determine, or clearly labelled general guidance. General guidance never claims that the re Kiosk accepts the item.

    Sample mode uses fixed, pre-authored examples to demonstrate the interface. Sample results are not evidence of live model accuracy.

    BUILT FOR A SMALL BEGINNING

    A campus habit,
    one item at a time.

    HKU Recycling Helper is an AILT9019 student project by Group 73, designed for newly arrived non-local HKU students. This is an independent course prototype, not an official HKU service.

    Your data

    Keep descriptions free of personal data. Live requests send the item description, permitted retrieved records, and task instructions to Alibaba Cloud Bailian through the local backend. The app does not keep query logs; provider processing is separate from local storage.

    A deliberately small pilot

    Any-language input, one item, one covered facility. Answers use canonical English evidence. No photos, live web searches, or nearest-bin recommendations. Sample mode is available without a key and makes no AI calls.
